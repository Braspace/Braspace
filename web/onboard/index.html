Simulador educacional, não é software de voo nem ferramenta aprovada pela NASA. Visibilidade do Sol e da Terra vem de um modelo sintético. Luz disponível não é potência elétrica real. Nenhum resultado é recomendação de voo.

Missão e geração de dados

Cada cenário gera as amostras a partir do modelo sintético, com o horário de início de cada cenário. Janelas curtas (por exemplo 72 h) podem não ter luz no modelo sintético: o ciclo é de cerca de 29,5 dias.
