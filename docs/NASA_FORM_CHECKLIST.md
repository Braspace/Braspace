## 2. Dados NASA reais

- [ ] Cada conjunto de dados citado no formulário aparece no projeto (código, notebook ou saída).
- [ ] Cada conjunto tem nome oficial, fonte (missão/instrumento/portal), versão ou data de acesso.
- [ ] Nenhum valor apresentado como dado NASA é, na verdade, ilustrativo ou gerado. Se houver dado simulado, ele está rotulado como tal.
- [ ] Os dados citados no texto batem com os arquivos ou saídas do projeto.

Fonte de referência para registrar: `data/NASA_SOURCES_TEMPLATE.md` (PR #44).

## 3. Transparência sobre IA (SI)

- [ ] A declaração diz claramente quais partes foram geradas ou auxiliadas por IA (código, texto, imagens, slides).
- [ ] Ferramentas e modelos de IA usados estão listados.
- [ ] Nenhuma parte gerada por IA é apresentada como trabalho humano sem essa ressalva.

## 4. Marca d'água, direitos autorais e originalidade

- [ ] Imagens, ícones, fontes e bibliotecas têm licença compatível com a submissão.
- [ ] Nenhum material de terceiros foi copiado sem atribuição.
- [ ] Imagens geradas por IA não usam marcas d'água de outros serviços sem permissão.
- [ ] O texto do projeto é original ou tem citação adequada.

## 5. Honestidade científica

- [ ] Nenhuma afirmação de precisão de missão ou de qualidade operacional sem validação.
- [ ] Limitações científicas estão descritas no texto.
- [ ] Resultados ilustrativos estão rotulados como ilustrativos.
- [ ] Incertezas e premissas dos cálculos estão declaradas.

## 6. Consistência entre entregas

- [ ] Resumo, detalhes, slides e demo dizem a mesma coisa.
- [ ] Número de slides da apresentação oficial: 7 ou menos.
- [ ] Os nomes dos membros e da equipe estão corretos.
